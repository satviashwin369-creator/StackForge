# StackForge Development Log

StackForge is a full-stack Internal Developer Platform (IDP) inspired by modern DevOps platforms like Portainer, Harness, and GitLab.

Tech Stack

### Frontend
- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Zustand

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- Redis
- JWT Authentication

### DevOps
- Docker
- Docker Compose
